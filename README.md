# Smart Civic Reporter

## About the Project
Smart Civic Reporter is an AI-powered civic issue reporting and tracking platform that helps citizens report public issues easily and track their resolution.

## Key Features
- 📸 Report civic issues with images
- 🤖 AI-powered issue identification
- 📍 Location-based complaint reporting
- 👨‍💼 Automatic department/officer assignment
- 📊 Complaint status tracking
- 🗺️ Interactive map
- 🛠️ Admin dashboard
- 📈 Complaint statistics and monitoring

## Technologies Used
- Frontend: HTML, CSS, JavaScript, React
- Backend: Base44 / REST APIs
- Database: Base44 Database
- AI/ML: Computer Vision
- Maps: OpenStreetMap + Leaflet.js
- Authentication: Role-Based Access

## Live Demo
https://fiery-civic-pulse-flow.base44.app

## Project Goal
To make civic issue reporting faster, transparent, and easier for citizens while helping authorities manage and resolve complaints efficiently.
