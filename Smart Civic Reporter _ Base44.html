Create a modern, professional, responsive web application called “Smart Civic Reporter” — an AI-powered civic issue reporting and tracking platform.

    PROJECT GOAL: The platform allows citizens/students to report real-world civic problems such as:

    • Potholes
    • Garbage accumulation
    • Broken streetlights
    • Water leakage
    • Damaged roads
    • Drainage problems
    • Illegal dumping
    • Other public infrastructure issues

    Users can upload an image of the issue, and AI classifies the issue automatically. The complaint is stored in the database and can be tracked until it is resolved.

    TECHNOLOGY STACK: Frontend:

    • HTML5
    • CSS3
    • JavaScript
    • Bootstrap or custom responsive CSS

    Backend:

    • PHP

    Database:

    AI:

    • Python
    • Machine Learning / Computer Vision
    • Create an API endpoint that receives the uploaded image and returns the predicted issue category.
    • For the prototype, provide a fallback/demo classification if the AI model is unavailable.

    MAP:

    • OpenStreetMap + Leaflet.js
    • Allow the user to select or capture the complaint location.
